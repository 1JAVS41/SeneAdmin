# SENE ADMIN

Aplicación Android del propietario de SENE.

Este repositorio inicia el proyecto desde cero. La implementación se realizará en una rama de trabajo y deberá mantener compatibilidad con el formato compartido de SENE VENTAS, sin modificar SERVER-SENE.

## Requisitos base
- Inventario maestro independiente.
- Lectura y gestión de la carpeta INVENTARIO SENE compartida con SENE VENTAS.
- Clave común del propietario; una clave incorrecta nunca modifica ni elimina archivos.
- Importación de reportes de trabajadores, control de nómina y registros por perfil.
- Compatibilidad con los formatos existentes antes de habilitar escrituras nuevas.
